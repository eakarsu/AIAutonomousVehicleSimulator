# Reproducible simulation runs

Governed runs pin scenario, map, sensor, policy, engine, random seed, resource caps, and a no-network/read-only-input sandbox. Results preserve artifacts and deterministic metrics; comparisons identify regression. Every response states that simulation is not real-world safety validation.

Bootstrap, migrations, and guarded seed are explicit. Start is non-mutating. Generated gaps are unmounted. Simulation engines, scenario standards, maps/assets, GPU workers, artifact stores, large coverage campaigns, and sim-to-real/field validation remain external deployment and engineering work.
